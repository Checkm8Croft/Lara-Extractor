## Coding Guideline

Lara-Extractor is a vibe-coded program, but if you'd like to improve something, feel free to do a PR!
AI generated code is ok

This project is born for helping TRLE builders for building their levels, where they can have the possibility of using assets directly from a specific Tomb Raider level.

## Issues

Have you found a problem with the program?

Make an issue! Describe clearly your problem, send screenshots if you can. Also set the label on your Issue

## Feature Requests

Do you have an idea for this program?

We'd happy to hear it! On the issues, you can also create a Feature Request. Describe clearly what you'd like to see on the program. Also set the label on your Feature Request

## Pull Requests

Would you like to implement a features you did on the repo?

Feel free to do it! Describe clearly what your PR does, check if you you used AI code, and send screenshots if you can. Also set the label on your PR
Follow the examples below for a good PR content:

### PR Content

Bad PR Content:
```txt
Implemented TR1 support
```

Good PR Content:
```txt
This PR adds the support for TR1 Levels

(Eventaully Screenshots)

```

### PR Commit Message

Bad:

`Added support for TR1 levels`

Good:

`extractor: implemented tr1 levels support` or `assets: fixed mismatched textures colors`

## Where to discuss

You can discuss of the project on the Issues and Discussions tab or also my [Discord Server](https://discord.gg/zmtkMK98hZ)

## What is not allowed

- Off-Topic Discussions: If you create an Issue/FR/PR, the content must be related to the content only. If you'd like to talk of other topics, join the discord server
- Respect: Unrespectful behaviours will immediately mean Issue/FR/PR closed
- Privacy: Beware of sharing your personal infomation on the code (Windows paths, your real name, etc...)
- Duplicated or repetitive content: Pay attention of not duplicate an Issue/FR of another one, and your Issue/FR/PR would be rejected, please don't insist for it


## AI-generated code

AI-generated code is allowed. However, contributors should make a reasonable effort to understand, test, and describe the changes they submit. Using AI is not, by itself, a reason to reject a contribution.

## Enforcement

If these rules are violated, project maintainers may remove content, request changes, close issues or pull requests, or restrict access to project spaces when necessary. The response will depend on the severity and context of the behavior.
